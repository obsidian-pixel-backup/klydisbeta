# UX Microcopy & UX Writing Standard

Microcopy refers to the small snippets of text (button labels, helper text, tooltips, error prompts) that guide users through interface interactions.

## Guidelines for Clear Microcopy

1. **Be Action-Oriented**: Use specific verbs for button labels (`Save Profile` instead of `Submit`; `Delete Workspace` instead of `OK`).
2. **Be Concise & Direct**: Eliminate unnecessary filler words (`Please click here to continue` $\rightarrow$ `Continue`).
3. **Use Active Voice**: `Your changes were saved` $\rightarrow$ `Saved changes`.

---

## Microcopy Writing Transformation Matrix

| Context | Poor Microcopy | High-Quality Microcopy |
| :--- | :--- | :--- |
| **Button Action** | `Submit` | `Create Account` |
| **Destructive Action** | `Are you sure?` | `Permanently delete "Project Alpha"?` |
| **Form Helper** | `Fill out info` | `We'll send your receipt to this email.` |
| **Error Message** | `Invalid input` | `Enter a valid phone number (e.g. 555-0199).` |

---

## Verification Checklist

- [ ] Button labels state the exact action result explicitly (`Save`, `Delete`, `Export PDF`).
- [ ] Helper text below inputs clarifies input format expectations.
- [ ] Microcopy uses consistent capitalization (Sentence case standard).
